
## Confidence Calibration

- **High**: Multiple independent reputable sources agree; recent (<12 months); first-hand data available.
- **Medium**: Some sources agree, some thin; mostly secondary sources; modest recency gap.
- **Low**: Few sources, conflicting reports, mostly opinion / blogs, or significant data gaps.

State the confidence level honestly — overconfident research is worse than
"I couldn't find good evidence here."
